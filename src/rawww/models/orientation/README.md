# Deep-OAD ONNX

`deep_oad.onnx` скачивается в фоне при открытии «Пакетного редактора» и не
входит в исходный репозиторий.

- источник: `https://shotsync.ru/media/ctrlka/models/deep-oad.onnx`;
- вариант: динамически квантованный INT8 Deep-OAD;
- SHA-256: `fed21a8aeacc49e362fb66bca1d67d333a4965087d1fc706c961221e334947b9`;
- URL и SHA-256 закреплены в `rawww.inpaint_pipeline`;
- заявленная карточкой модели лицензия — MIT;
- вход: `float32`, NCHW, `1×3×224×224`; выход: один угол в градусах.

Модель основана на Deep Image Orientation Angle Detection Маджи и Бозе. Она
оценивает визуальную ориентацию снимка, а не геометрическую линию горизонта,
поэтому интерфейс применяет только коррекции не более 15°.
